# arrow_build_leaos
 build script for arrow

need repo init before start build script

repo init -u https://github.com/ArrowOS/android_manifest.git -b arrow-13.1

To build Vanilia version without su

bash arrow_build_leaos/build.sh treble 64BVN

To build Gapps version without su

bash arrow_build_leaos/build.sh treble 64BGN
